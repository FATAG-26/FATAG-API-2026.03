# 📑 Requisitos do Cliente

Requisitos levantados a partir do documento de Aprendizagem por Projetos Integrados 2026-2, com o tema **Combustível na Medida: Análise de Dados e Transparência no IPEM-SP**.

## ⚙️ Requisitos Funcionais

| Código | Requisito |
| :----: | --------- |
| R01 | Limpar e normalizar a base de dados das bombas de combustível: padronização geográfica (municípios e regionais), temporal e sanitização das colunas de medição (erros em mL, status de aprovação, reprovação ou interdição). |
| R02 | Identificar as taxas regionais de conformidade das bombas fiscalizadas. |
| R03 | Identificar os principais motivos de reprovação das bombas. |
| R04 | Gerar o ranking de municípios e regiões auditadas. |
| R05 | Disponibilizar uma aplicação web com dashboard que permita filtrar os resultados por município e região. |
| R06 | Exibir cards de KPI: Total de Bombas Periciadas, % de Aprovação e Total de Autuações. |
| R07 | Exibir gráficos interativos com as visualizações mais relevantes. |

## 📋 Requisitos Não Funcionais

| Código | Requisito |
| :----: | --------- |
| RNF01 | Manual de Instalação (requisito Fatec, obrigatório, no Git). |
| RNF02 | Manual do Usuário (requisito Fatec, obrigatório). |
| RNF03 | Documentação da API (Application Programming Interface). |
| RNF04 | Modelagem de Banco de Dados ou Arquivo de dados. |
